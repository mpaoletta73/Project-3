Checkpoint Notes

Data Source and Transformation

We got the data from the Google Cloud CMIP6 Zarr catalog using the same general steps as the class notebook. We queried the catalog with Pandas, opened the NCAR CESM2 historical Omon/tos store with gcsfs and xarray, pulled out a few equatorial Pacific points, and saved the smaller dataset as a CSV for D3. Since the historical run ends in 2014, these graphs focus on 1996-2014.

Design Rationale

We use SST anomaly instead of raw temperature because El Nino is about how much the Pacific changes from normal conditions. The color scale is centered at 0°C, with blue showing cooler-than-normal water, white showing near-normal conditions, and red showing warmer-than-normal water. The graphs start with the overall time pattern, then show seasonality, regional differences, and a first version of the interactive idea.

Video Script Pointers

Then we can briefly walk through the time series, seasonal heatmap, phase comparison, regional comparison, longitude profile, and prototype.
