Since the historical run ends in 2014, these graphs focus on 1996-2014.

Design Rationale

We use SST anomaly instead of raw temperature because El Nino is about how much the Pacific changes from normal conditions. The color scale is centered at 0°C, with blue showing cooler-than-normal water, white showing near-normal conditions, and red showing warmer-than-normal water. The graphs start with the overall time pattern, then show seasonality, regional differences, and a first version of the interactive idea.

Project Write-Up

Research Question

How does El Niño alter key environmental indicators — sea surface temperature, precipitation, vegetation cover, and atmospheric conditions — across the Pacific region, as observed in NASA satellite and NOAA climate data?

Data Sources

  • NOAA Oceanic Niño Index (ONI): 3-month rolling average sea-surface temperature anomalies in the Niño 3.4 region (5°N–5°S, 170°W–120°W), 1950–present. Fetched as a plain-text table and stored locally as data/oni.csv to avoid browser CORS restrictions. CPC NCEP
  • NASA POWER API (T2M — 2 m Surface Temperature): Monthly mean near-surface air temperature (°C) at point locations, 1990–2024, retrieved in JSON format directly in the browser. Used in Visualization 3. NASA POWER
  • NASA POWER API (PRECTOTCORR — Precipitation): Monthly bias-corrected precipitation (mm/day) at point locations, 1990–2024. Used in Visualization 4. NASA POWER
  • Natural Earth (world-atlas): 110 m resolution country polygons used to render the base map in Visualization 3, served via jsDelivr CDN. world-atlas

Visualization 3 (Matthew Paoletta) — Visual Encodings & Interaction

Vis 3 uses a geographic point map as its primary mark type, with five circles positioned at their real-world coordinates on a Natural Earth projection. Color is the primary encoding channel — a diverging red–blue scale maps each region’s annual temperature anomaly, where red signals warming above the regional long-term average (the El Niño signature) and blue signals cooling. Geographic position was chosen over a line chart because the question “where does El Niño warm the world?” is inherently spatial; placing circles on a map lets the viewer instantly see which regions warm together versus in opposition. A line chart was the original approach but was replaced because five lines on different absolute temperature scales created an unreadable spaghetti plot that obscured the ENSO signal. Three interactions support exploration: a year slider to manually inspect any year, a Play button that animates 1990–2024 at one year per second so the viewer can watch El Niño events pulse red across regions, and a hover tooltip showing the exact anomaly value and regional baseline.

Visualization 4 (Matthew Paoletta) — Visual Encodings & Interaction

Vis 4 uses a line chart with time on the X axis and monthly precipitation (mm/day) on the Y axis. A single colored line represents the selected region, with El Niño and La Niña months shaded as red and blue background bands respectively — overlaying ENSO phase directly onto the precipitation trace makes wet/dry shifts during ENSO events immediately visible without requiring the viewer to cross-reference a separate chart. A focus+context layout (main chart plus a brush-zoomable mini-chart below) was chosen because 35 years of monthly data at full resolution is too dense to read individual events; the brush lets the viewer isolate a specific El Niño episode (e.g. 1997–98) and inspect it closely. A dropdown switches between all five regions, rescaling the Y axis to each region’s own range so that arid Peru and monsoon-driven India are both readable. Hover tooltips show the exact precipitation value, ONI anomaly, and ENSO status for any month.

Visualization 5 (Thomas Deitel) — Visual Encodings & Interaction

Vis 5 is an exploratory multi-line chart for quickly comparing how each available environmental indicator changes over time. Year is encoded on the X axis and the selected indicator's measured value is encoded by vertical position, which is the most direct channel for reading temporal change. Region is encoded by line color so multiple regions can be compared when the selected variable includes more than one region. The measure buttons act as a dynamic query filter, letting the viewer move between temperature, precipitation, CO2, and sea level without mixing incompatible units on one axis. Hover interaction provides details-on-demand for the nearest year, and clicking legend items hides or restores regions so the viewer can isolate one line when comparisons get crowded.

Data Transformations

Visualization 3 — Temperature Anomaly Map

  • Sentinel filtering: NASA POWER returns -999 for missing months; these values are dropped before any calculation.
  • Monthly → annual aggregation: The 12 monthly T2M values for each year are averaged into a single annual mean per region, reducing 420 monthly frames to 35 annual steps and eliminating the seasonal cycle from the animation.
  • Anomaly normalization: Each region's long-term mean (average of all annual means, 1990–2024) is subtracted from its yearly value, producing a temperature anomaly in °C. This removes absolute temperature differences between regions (e.g. India averages ~27°C; Australia ~21°C) so the color scale reflects only ENSO-driven departures from normal, not geographic climate differences.
  • ENSO classification: A year is labeled El Niño if 5 or more of its 12 monthly ONI anomalies are ≥ +0.5°C, and La Niña if 5 or more are ≤ −0.5°C.

Visualization 4 — Precipitation Time Series

  • Sentinel filtering: PRECTOTCORR values of -999 are removed before plotting.
  • Per-region Y-axis rescaling: When the user switches regions via the dropdown, the Y-axis domain is recomputed to that region's data range (0 to 110% of its maximum), preventing misleadingly compressed or clipped views across regions with very different precipitation totals.
  • ONI season-to-month mapping: The ONI file uses 3-month season codes (e.g. DJF, MAM). These are mapped to their middle month (DJF → January, MAM → April, etc.) to align ENSO shading bands with the monthly precipitation x-axis.

Visualization 5 — Environmental Indicator Explorer

  • Typed parsing: Year and value fields are converted from strings to numbers, and rows with invalid critical fields are dropped.
  • Duplicate aggregation: Rows with the same year, variable, and region are averaged before plotting so repeated observations would not silently receive extra weight.
  • Dynamic filtering: The selected measure filters the dataset to a single unit at a time, preventing temperature, precipitation, CO2, and sea level from being compared on a misleading shared scale.
